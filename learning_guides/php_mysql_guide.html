🚀 Tổng Quan PHP+MySQL

PHP (Hypertext Preprocessor) là ngôn ngữ lập trình server-side mạnh mẽ, kết hợp với MySQL để tạo ra các ứng dụng web động và tương tác.

✅ Ưu Điểm

  • Dễ học và sử dụng
  • Cộng đồng lớn
  • Nhiều framework
  • Tương thích tốt với hosting

🔧 Ứng Dụng

  • Website động
  • E-commerce
  • CMS
  • Web API

⚙️ Cài Đặt Môi Trường

1. XAMPP (Windows/Mac/Linux)

XAMPP là gói cài đặt đơn giản nhất bao gồm Apache, MySQL, PHP và phpMyAdmin.

Tải XAMPP 
# Tải từ: https://www.apachefriends.org/
# Cài đặt và khởi động Apache + MySQL
# Truy cập: http://localhost/phpmyadmin

2. Cài Đặt Riêng Lẻ

Ubuntu/Debian 
sudo apt update
sudo apt install apache2 php mysql-server php-mysql
sudo systemctl start apache2
sudo systemctl start mysql

Hàm và Logic

functions.php 
<?php
// Định nghĩa hàm
function calculateArea($width, $height) {
    return $width * $height;
}

// Sử dụng hàm
$area = calculateArea(10, 5);
echo "Diện tích: $area";

// Điều kiện
if ($area > 20) {
    echo "<p>Diện tích lớn</p>";
} elseif ($area > 10) {
    echo "<p>Diện tích trung bình</p>";
} else {
    echo "<p>Diện tích nhỏ</p>";
}

// Vòng lặp
for ($i = 1; $i <= 5; $i++) {
    echo "Số: $i<br>";
}
?>

🗄️ MySQL & Database

Kết Nối Database

database.php 
<?php
// Thông tin kết nối
$host = "localhost";
$username = "root";
$password = "";
$database = "mywebsite";

// Tạo kết nối
$conn = new mysqli($host, $username, $password, $database);

// Kiểm tra kết nối
if ($conn->connect_error) {
    die("Kết nối thất bại: " . $conn->connect_error);
}

echo "Kết nối thành công!";
$conn->close();
?>

Tạo Bảng và Thêm Dữ Liệu

create_table.sql 
-- Tạo database
CREATE DATABASE mywebsite;
USE mywebsite;

-- Tạo bảng users
CREATE TABLE users (
    id INT AUTO_INCREMENT PRIMARY KEY,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- Tạo bảng posts
CREATE TABLE posts (
    id INT AUTO_INCREMENT PRIMARY KEY,
    title VARCHAR(200) NOT NULL,
    content TEXT,
    user_id INT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id)
);

Thao Tác CRUD

crud_operations.php 
<?php
// CREATE - Thêm user mới
$sql = "INSERT INTO users (username, email, password) VALUES (?, ?, ?)";
$stmt = $conn->prepare($sql);
$stmt->bind_param("sss", $username, $email, $hashed_password);
$stmt->execute();

// READ - Lấy danh sách users
$sql = "SELECT * FROM users ORDER BY created_at DESC";
$result = $conn->query($sql);
while ($row = $result->fetch_assoc()) {
    echo "Username: " . $row["username"] . "<br>";
}

// UPDATE - Cập nhật user
$sql = "UPDATE users SET email = ? WHERE id = ?";
$stmt = $conn->prepare($sql);
$stmt->bind_param("si", $new_email, $user_id);
$stmt->execute();

// DELETE - Xóa user
$sql = "DELETE FROM users WHERE id = ?";
$stmt = $conn->prepare($sql);
$stmt->bind_param("i", $user_id);

⚠️ Lưu ý: Luôn sử dụng Prepared Statements để tránh SQL Injection!

register.php 
<?php
session_start();

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = trim($_POST["username"]);
    $email = trim($_POST["email"]);
    $password = $_POST["password"];
    
    // Validate dữ liệu
    if (empty($username) || empty($email) || empty($password)) {
        $error = "Vui lòng điền đầy đủ thông tin";
    } else {
        // Hash password
        $hashed_password = password_hash($password, PASSWORD_DEFAULT);
        
        // Thêm vào database
        $sql = "INSERT INTO users (username, email, password) VALUES (?, ?, ?)";
        $stmt = $conn->prepare($sql);
        $stmt->bind_param("sss", $username, $email, $hashed_password);
        
        if ($stmt->execute()) {
            $_SESSION["message"] = "Đăng ký thành công!";
            header("Location: login.php");
            exit();
        } else {
            $error = "Có lỗi xảy ra, vui lòng thử lại";
        }
    }
}
?>

Hệ Thống Session

login.php 
<?php
session_start();

if ($_SERVER["REQUEST_METHOD"] == "POST") {
    $username = $_POST["username"];
    $password = $_POST["password"];
    
    $sql = "SELECT id, username, password FROM users WHERE username = ?";
    $stmt = $conn->prepare($sql);
    $stmt->bind_param("s", $username);
    $stmt->execute();
    $result = $stmt->get_result();
    
    if ($result->num_rows == 1) {
        $user = $result->fetch_assoc();
        if (password_verify($password, $user["password"])) {
            $_SESSION["user_id"] = $user["id"];
            $_SESSION["username"] = $user["username"];
            header("Location: dashboard.php");
            exit();
        } else {
            $error = "Password không đúng";
        }
    } else {
        $error = "Username không tồn tại";
    }
}
?>

Bảo Vệ Chống XSS

xss_protection.php 
<?php
// Bảo vệ chống XSS
function escapeHtml($data) {
    return htmlspecialchars($data, ENT_QUOTES, 'UTF-8');
}

// Sử dụng
$user_input = "<script>alert('XSS')</script>";
$safe_output = escapeHtml($user_input);
echo $safe_output; // Sẽ hiển thị text thay vì chạy script
?>
✅ Best Practices:
  • Sử dụng Prepared Statements
  • Validate và sanitize input
  • Hash passwords với password_hash()
  • Sử dụng HTTPS
  • Giữ PHP và extensions cập nhật

  4. Import database

    Import SQL file vào database của hosting

  5. Cập nhật config

    Thay đổi thông tin kết nối database

File .htaccess

.htaccess 
# Bảo mật
Options -Indexes
ServerSignature Off

# Rewrite URL
RewriteEngine On
RewriteCond %{REQUEST_FILENAME} !-f
RewriteCond %{REQUEST_FILENAME} !-d
RewriteRule ^(.*)$ index.php?url=$1 [QSA,L]

# Bảo vệ file nhạy cảm
<Files "config.php">
    Order allow,deny
    Deny from all
</Files>

# Cache static files
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType text/css "access plus 1 month"
    ExpiresByType application/javascript "access plus 1 month"
    ExpiresByType image/png "access plus 1 month"
    ExpiresByType image/jpg "access plus 1 month"
</IfModule>
💡 Tip: Test website trên local trước khi upload lên hosting. Sử dụng hosting có hỗ trợ PHP 8.0+ và MySQL 8.0+.
